# SignBridge

**Breaking Communication Barriers Between Deaf, Mute, and Hearing Individuals**

## Overview

SignBridge is an AI-powered accessibility and communication platform designed to facilitate seamless, real-time communication between deaf, mute, and hearing individuals.

The system combines computer vision, hand gesture recognition, speech recognition, text-to-speech synthesis, and sign language avatar generation to create a complete bidirectional communication experience.

Unlike traditional sign language translation tools that focus on only one direction of translation, SignBridge enables:

* Sign Language → Text
* Sign Language → Speech
* Speech → Text
* Speech → Sign Language Avatar

The goal of SignBridge is to eliminate communication barriers and promote inclusion in schools, hospitals, workplaces, government institutions, public services, and everyday interactions.

---

# Vision

To create an intelligent communication bridge that allows deaf, mute, and hearing individuals to communicate naturally without requiring either party to learn the other's language.

---

# Core Problem

Millions of deaf and mute individuals face communication challenges daily because most hearing individuals do not understand sign language.

Existing solutions often:

* Require human interpreters.
* Support only one-way communication.
* Lack real-time interaction.
* Have poor accessibility.
* Do not provide natural conversational experiences.

SignBridge addresses these limitations through a fully integrated AI-powered communication platform.

# Software Architecture

## Main Components

### main.py

Application entry point.

Responsibilities:

* Camera management
* Frame processing
* UI updates
* Gesture processing
* Event handling
* TTS integration

---

### gesture_engine.py

Core recognition engine.

Contains:

#### FeatureExtractor

Extracts hand features from MediaPipe landmarks.

Functions:

* Finger state detection
* Landmark normalization
* Bounding box generation
* Distance calculations

#### GestureClassifier

Classifies gestures using extracted features.

Functions:

* Pattern matching
* Confidence calculation
* Gesture scoring

#### GestureSmoothing

Provides temporal stabilization.

Functions:

* Frame buffering
* Confirmation thresholds
* Noise reduction
* Debouncing

#### SentenceBuffer

Builds meaningful communication sequences.

Functions:

* Gesture accumulation
* Sentence generation
* Automatic clearing
* Cooldown management

---

### ui_overlay.py

Responsible for visual feedback.

Features:

* Landmark rendering
* Bounding boxes
* Side panels
* Status displays
* FPS monitoring
* Sentence display

---

### tts_engine.py

Speech synthesis subsystem.

Responsibilities:

* Voice generation
* Speech queue management
* Audio output

---

### serial_comm.py

External device communication.

Responsibilities:

* LCD communication
* Embedded device integration
* Real-time message transfer
